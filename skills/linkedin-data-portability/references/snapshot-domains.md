# Member Snapshot Domains

All domains are **case-sensitive**. Use exactly as listed when querying the Member Snapshot API with `?domain=DOMAIN_NAME`.

| Domain | Description |
|--------|-------------|
| `ACCOUNT_HISTORY` | Date and time account status changed within the last year |
| `ACTOR_SAVE_ITEM` | Saved date and URL of saved posts, articles, or other content |
| `ADS_CLICKED` | Ads clicked on |
| `ADS_LAN` | LAN ads engagement info: date, advertising ID, web page/app, action type |
| `AD_TARGETING` | Info used by LinkedIn to determine which ads to show |
| `ALL_COMMENTS` | Comments made (excluding Group posts) |
| `ALL_LIKES` | Reaction types made to posts |
| `ALL_VOTES` | Polls created and voted on |
| `ARTICLES` | Articles authored |
| `CAUSES_YOU_CARE_ABOUT` | Causes on profile |
| `CERTIFICATIONS` | Certifications on profile |
| `COMPANY_FOLLOWS` | Companies/entities followed |
| `CONNECTIONS` | Name, position, company, and connection date of 1st degree connections |
| `CONTACTS` | Imported contacts |
| `COURSES` | Courses on profile |
| `EDUCATION` | Schools, dates, degrees, activities |
| `EMAIL_ADDRESSES` | Email address history (past and present) |
| `ENDORSEMENTS` | Given and received endorsements |
| `Events` | Events attended, declined, or requested to attend |
| `GROUPS` | LinkedIn groups membership |
| `HONORS` | Honors on profile |
| `IDENTITY_CREDENTIALS_AND_ASSETS` | Private identity asset and credential data |
| `INBOX` | Messages sent and received |
| `INFERENCE_TAKEOUT` | Key inferences based on profile and activity |
| `INSTANT_REPOSTS` | Repost date, time, and link |
| `INVITATIONS` | Invitations sent and received |
| `JOB_APPLICANT_SAVED_ANSWERS` | Answers to basic job application questions |
| `JOB_APPLICATIONS` | Jobs applied to |
| `JOB_POSTINGS` | Jobs posted |
| `JOB_SEEKER_PREFERENCES` | Preferred job types, locations, industries, company sizes, dream companies, titles, activity level |
| `LANGUAGES` | Languages and proficiency levels |
| `LEARNING` | LinkedIn Learning videos watched |
| `LEARNING_COACH_AI_TAKEOUT` | Past conversations with LinkedIn Learning chatbot |
| `LEARNING_COACH_INBOX` | Past conversations with LinkedIn Learning chatbot |
| `LEARNING_ROLEPLAY_INBOX` | Insights from interactive learning scenarios |
| `MARKETPLACE_ENGAGEMENTS` | Event name, date/time, status, external URL |
| `MARKETPLACE_OPPORTUNITIES` | Services looking for on Services Marketplace |
| `MARKETPLACE_PROVIDERS` | Services provided on Services Marketplace |
| `MEMBER_FOLLOWING` | People followed on LinkedIn |
| `MEMBER_SHARE_INFO` | Shared/re-shared posts: date, URL, comments, visibility |
| `ORGANIZATIONS` | Organizations on profile |
| `PATENTS` | Patents on profile |
| `PHONE_NUMBERS` | Phone numbers on account |
| `POSITIONS` | Job roles: company, title, description, location, dates |
| `PROFILE` | Basic biographical info (name, headline, summary, location, etc.) |
| `PROFILE_SUMMARY` | AI-generated profile summary |
| `PROJECTS` | Projects on profile |
| `PUBLICATIONS` | Publications on profile |
| `RECEIPTS` | Purchase details associated with account |
| `RECEIPTS_LBP` | LinkedIn service purchases |
| `RECOMMENDATIONS` | Recommendations received and given |
| `REGISTRATION` | Date joined LinkedIn |
| `REVIEWS` | Ratings/reviews for products, service providers, LinkedIn Learning |
| `RICH_MEDIA` | URLs to photos, videos, documents shared |
| `SAVED_JOBS` | Jobs saved for future reference |
| `SAVED_JOB_ALERTS` | Job alerts with saved date and URLs |
| `SEARCHES` | Recent searches |
| `SECURITY_CHALLENGE_PIPE` | Sign-in challenge events: date, IP, user agent, country, challenge type |
| `SKILLS` | Skills on profile |
| `TALENT_QUESTION_SAVED_RESPONSE` | Answers to job poster questions |
| `TEST_SCORES` | Test scores on profile |
| `TRUSTED_GRAPH` | Verified identity, workplace, education info (via CLEAR) |
| `VOLUNTEERING_EXPERIENCES` | Volunteering: org, role, cause, dates, description |
| `easyapply-blocking` | Job application records on third-party ATS |
